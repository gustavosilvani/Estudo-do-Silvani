# 🛠️ Ferramentas Recomendadas

Ferramentas úteis para desenvolvimento e estudo.

## 📝 Editores e IDEs

### Recomendados

- **Visual Studio Code** - Editor gratuito e extensível
  - Extensões úteis: ESLint, Prettier, GitLens
- **IntelliJ IDEA** - IDE completa para Java/Kotlin
- **WebStorm** - IDE para JavaScript/TypeScript
- **Rider** - IDE para .NET

## 🔍 Análise de Código

### Linters

- **ESLint** - Para JavaScript/TypeScript
- **Pylint** - Para Python
- **RuboCop** - Para Ruby
- **SonarLint** - Multi-linguagem

### Formatters

- **Prettier** - Formatador universal
- **Black** - Para Python
- **gofmt** - Para Go

## 🧪 Testes

### Frameworks

- **Jest** - Para JavaScript/TypeScript
- **JUnit** - Para Java
- **pytest** - Para Python
- **RSpec** - Para Ruby

### Cobertura

- **Istanbul/NYC** - Para JavaScript
- **JaCoCo** - Para Java
- **Coverage.py** - Para Python

## 📊 Diagramas

### Ferramentas

- **Mermaid** - Diagramas em markdown
- **PlantUML** - Diagramas UML
- **Draw.io** - Diagramas visuais
- **Excalidraw** - Diagramas simples
