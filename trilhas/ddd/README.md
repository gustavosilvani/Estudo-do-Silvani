# 🏛️ DDD - Domain-Driven Design

## 📖 Sobre

Esta trilha ensina Domain-Driven Design (DDD), uma abordagem para desenvolvimento de software complexo focada no domínio do negócio.

## 🎯 Objetivos de Aprendizado

Ao final desta trilha, você será capaz de:

- Modelar domínios complexos usando DDD
- Identificar contextos limitados (bounded contexts)
- Implementar entidades, value objects e aggregates
- Criar domain services e application services
- Aplicar CQRS e event-driven architecture

## 📋 Pré-requisitos

- C#/.NET intermediário
- SOLID principles
- Clean Code
- Testes unitários
