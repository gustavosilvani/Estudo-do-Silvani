# 🎯 Design Patterns - Padrões de Projeto

## 📖 Sobre

Esta trilha cobre os **Design Patterns** (Padrões de Projeto) clássicos do livro *"Design Patterns: Elements of Reusable Object-Oriented Software"* (Gang of Four - GoF, 1994), além de padrões amplamente usados em aplicações .NET como Repository e Unit of Work.

Padrões de projeto são soluções consolidadas para problemas recorrentes no design de software. Eles complementam os princípios SOLID e são aplicados nos microsserviços de exemplo deste repositório.

## 🎯 Objetivos de Aprendizado

Ao final desta trilha, você será capaz de:

- Entender o que são padrões de projeto e quando usá-los
- Conhecer os padrões criacionais, estruturais e comportamentais (GoF)
- Aplicar Factory, Singleton, Strategy, Observer, Repository e Unit of Work em C#
- Identificar onde cada padrão já é usado nos projetos do repositório
- Evitar uso indevido (quando o padrão não resolve o problema real)

## 📋 Pré-requisitos

- Orientação a objetos em C#
- Conhecimento básico de SOLID (recomendado ter concluído a trilha SOLID)
- Noções de interfaces e injeção de dependência
