# 🗄️ SQL Server - Banco de Dados Relacional

## 📖 Sobre

Esta trilha ensina SQL Server e Entity Framework Core para desenvolvimento de aplicações com persistência robusta.

## 🎯 Objetivos de Aprendizado

Ao final desta trilha, você será capaz de:

- Dominar SQL básico e avançado
- Projetar bancos de dados relacionais
- Usar Entity Framework Core eficientemente
- Implementar migrations e versionamento
- Otimizar queries e performance
- Trabalhar com transações e concorrência

## 📋 Pré-requisitos

- C#/.NET básico
- Conceitos de banco de dados
- Lógica de programação

4. **[03 - Entity Framework Core](./03-entity-framework.md)** - ORM e mapeamento
