# 🎯 SOLID - Princípios de Design Orientado a Objetos

## 📖 Sobre

Esta trilha cobre os cinco princípios fundamentais de design orientado a objetos conhecidos como SOLID. Estes princípios foram **compostos** por Robert C. Martin (Uncle Bob) no início dos anos 2000, mas representam um **trabalho coletivo** de especialistas que refinaram conceitos de design de software orientado a objetos ao longo de décadas:

- **Barbara Liskov** (1987): Introduziu o Princípio de Substituição de Liskov (LSP)
- **Bertrand Meyer** (1988): Criador do Princípio Aberto/Fechado (OCP) e pioneiro na Programação por Contrato
- **Jim Coplien**: Contribuiu com padrões de linguagem e arquiteturas organizacionais
- **Robert C. Martin**: Compilou e formalizou os princípios SOLID, criando o acrônimo

Estes princípios são essenciais para escrever código manutenível, extensível e testável, e surgiram como resposta à necessidade crescente de princípios de projeto de software diante da complexidade crescente dos sistemas.

## 🎯 Objetivos de Aprendizado

Ao final desta trilha, você será capaz de:

- Entender cada um dos cinco princípios SOLID
- Identificar violações dos princípios em código existente
- Aplicar os princípios na prática
- Refatorar código para seguir os princípios SOLID
- Reconhecer quando e como usar cada princípio

## 📋 Pré-requisitos

- Conhecimento básico de programação orientada a objetos
- Familiaridade com classes, interfaces e herança
- Experiência com pelo menos uma linguagem OO (TypeScript/JavaScript, Java, C#, etc.)
- Compreensão básica de design de software
